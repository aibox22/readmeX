# 英雄图混合合成

精选自 oil-oil 的混合 SVG 制作指南。入口已问过生图许可；未明确同意就不要执行此流程。

先看项目现有截图、Logo、真实输出和插画是否已经足够。只有生成素材能够表达项目身份、机制或独特材质时才使用它。SVG 精确控制排版、标签、颜色和布局；栅格层只承担项目专属形象、材质或光照，不能代替功能证据。

## 文件与生产顺序

1. 冻结 `.readmex/optimize/story.md` 中的故事与视觉规格。
2. 写出素材的沟通任务，在 `.readmex/optimize/imagegen/hero-layout.svg` 预留有名称的素材区域。
3. 使用可用的 imagegen 技能或生图工具生成匹配裁切、朝向、留白、调色与光照的素材。精确文字、字母、Logo 和 UI 标签不交给生图模型。
4. 把素材存为 `.readmex/optimize/imagegen/hero-subject.png`，最终提示词存为 `hero-prompt.txt`。按工具本身的透明处理流程执行；不要复制它的背景移除实现。
5. 合成 SVG 布局与栅格层，导出 `readme/assets/hero.png`。检查实际导出文件，而不是只检查源布局。

整页模式发布 PNG；素材模式尚未被 README 引用的 PNG 暂存 `.readmex/optimize/preview/assets/hero.png`。SVG 布局和素材是中间源文件。不要把依赖绝对路径、未解析相对路径或远程图片的 SVG 引用进 README。若同时启用 GIF，另保留可独立显示的同名 `hero.svg`，其关键内容不依赖栅格层；整页模式发布并在图下链接回退文件，素材模式则一起暂存。

## 素材提示词

写明素材类型、项目关联、朝向与裁切、光照、调色和负空间；要求单一主体、四周足够留白、无文字/字母/Logo/水印。硬边不透明主体可用项目色之外的纯色抠图背景；毛发、玻璃、烟雾或半透明材质可用匹配背景合成，避免破坏边缘。

透明素材需检查 alpha 通道、四角透明、覆盖范围、浅/深背景边缘、细部和色边。匹配背景素材则检查与布局的边界、阴影和色彩衔接，不能把它声称为透明素材。

## 验收

在 900 与 360 宽预览最终 PNG：文字可读、裁切干净、图与文字均衡、没有素材缺失或水印、大小合理、alt 有意义。记录生图模式、最终提示词、布局源、素材和发布图路径。生成或合成失败时继续静态 SVG，并记录原因，不重新提问。
