# Logo branch

Write `images/logo.svg` in the target repository. Create `images/` when it is missing. Replace an existing `images/logo.svg`.

Draw one mark that fits the repository's name and primary language from the scan. Use a simple geometric shape and a small palette. The SVG is self-contained: a `viewBox`, filled shapes, and no external images, fonts, or scripts. Leave letters and words out of the graphic.

The logo is done when `images/logo.svg` exists in the target and is the file written in this run.
